▶PlayBack — User Guide

PlayBack is playlist video playback for live events: cue clips on the control surface, punch TAKE, and the program output plays them full screen on the selected display. Any browser on the network can mirror the control surface or the output.

Quick Start

  1. Drop video files anywhere on the control window (or click Add Files…).
  2. Click a clip to cue it (blue outline). Double-click to play it immediately.
  3. Press TAKE (or Space). The output window opens by itself if it isn't already up.
  4. KILL (K) cuts to black instantly. Pause/Resume is P.

When A Clip Ends

ModeBehavior
HoldPause on the last frame (default)
BlackCut to black
Play NextPlay the next clip in the list immediately
Cue NextLoad the next clip paused on its first frame

A clip with its ⟳ Loop checkbox set (in the playlist) loops between its in and out points instead, whatever the end mode.

Trim, Rehearsal & Levels

  • In/out points: play or scrub to the spot, press I (Mark In) or O (Mark Out) — or use the buttons under the transport. Timecodes, playlist totals and end-of-clip behavior follow the trim; markers appear on the progress bar. Clear removes them.
  • Rehearsal jumps: Last 30 / 20 / 10 jump to that many seconds before the clip's out point.
  • Audio: master volume at the bottom right; each clip also has its own level (select the clip, use the slider under the playlist).
  • Geometry: aspect (Fit / Fill / Stretch / 16:9 / 4:3) and scale apply to the output and the preview.

Remote Access

Any device on the same network can open:

Control surface: http://10.1.10.140:3100/control
Program output / confidence monitor: http://10.1.10.140:3100/output

Browsers block unmuted autoplay — a web output view shows “Click to start playback” once; click it and it will follow every Take from then on.

Formats

PlayBack plays what the platform's media engine plays. On a Mac that is AVFoundation, so ProRes .mov files play natively with hardware decode, alongside H.264 and HEVC. H.264/AAC in .mp4/.mov (ideally with faststart) is the safe bet everywhere — it is also what web-remote previews in Chrome can render; ProRes shows only on the playback machine's own windows.

Troubleshooting

  • Clip shows “missing” — the file moved since it was added. Put it back or re-add it. Playlists store paths, not copies.
  • No remote access — check the Server IP in the footer and that the machines share a network. The port (default 3100) is configurable in Advanced Settings.
  • Black output but timers running — the clip's codec isn't playable; the output shows a “Cannot play” notice. Transcode to H.264.
